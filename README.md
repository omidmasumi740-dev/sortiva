# Sortiva

**Your Files. Perfectly Organized.**

Sortiva is a Windows desktop app that keeps your folders tidy. It sorts files by type and date, reads the real shooting date from photos and videos, finds duplicates, cleans up old installers, and can organize on a schedule — even while the app is closed.

## Download

Get the latest installer from the [Releases](https://github.com/omidmasumi740-dev/sortiva/releases) page and run it. Existing settings, history and an activated Pro license are kept across upgrades.

## Highlights

- One-click organization by type and date (Jalali and Gregorian folders)
- Auto Organize with interval or daily schedule, folder watch and Task Scheduler support; the Simple mode is free
- Rules engine with content/OCR conditions, destination and rename templates
- Duplicate finder and installer/Temp cleanup with Recycle Bin safety
- Preview with conflict warnings, full history with undo, CSV/JSON export
- Light and dark themes, Persian and English interface, built-in updater
