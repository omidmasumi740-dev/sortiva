حریم خصوصی Sortiva

Sortiva فایل‌ها را روی همان رایانه مرتب می‌کند. این صفحه می‌گوید چه داده‌ای جابه‌جا می‌شود، چه چیزی به اینترنت می‌رود و چه چیزی نمی‌رود.

آخرین به‌روزرسانی: آبان ۱۴۰۵

مرتب‌سازی روی دستگاه شما

فایل‌ها و پوشه‌ها روی همان ویندوز شما خوانده و جابه‌جا می‌شوند. Sortiva فایل‌ها، عکس‌ها یا ویدیوها را به سرور خودش آپلود نمی‌کند و محتوای آن‌ها را نمی‌خواند؛ فقط نام، نوع، تاریخ و در صورت نیاز فرادادهٔ عکس (EXIF) را برای مرتب‌سازی می‌خواند.

حساب، دورهٔ آزمایشی و پرداخت

برای دورهٔ آزمایشی Pro و خرید، یک حساب رایگان با ایمیل یا GitHub لازم است. ایمیل حساب برای ورود، بازیابی رمز و ثبت اینکه دورهٔ آزمایشی هر شخص یک‌بار استفاده شود روی سرور نگه‌داری می‌شود. اطلاعات پرداخت را فروشندهٔ پرداخت پردازش می‌کند و Sortiva شمارهٔ کارت را نمی‌بیند و ذخیره نمی‌کند.

اینترنت چه زمانی استفاده می‌شود؟

فقط برای بررسی به‌روزرسانی، ورود به حساب و خرید Pro. اگر از حساب استفاده نکنید، مرتب‌سازی کاملاً آفلاین کار می‌کند.

این وب‌سایت

سایت Sortiva هیچ تبلیغ، ردیاب یا ابزار تحلیلی شخص ثالث ندارد. فونت و تصاویر از همان دامنه بارگذاری می‌شوند. فرم آنلاین نداریم؛ ارتباط از طریق ایمیل است.

حذف حساب و داده

برای حذف حساب و اطلاعات مرتبط با دورهٔ آزمایشی، از همان ایمیل حساب به sortivasupport@gmail.com پیام بدهید. فایل‌های شما روی دستگاهتان هستند و حذف حساب به آن‌ها کاری ندارد.

تغییرات این سیاست

اگر این سیاست تغییر کند، همین صفحه به‌روزرسانی می‌شود و تاریخ بالای صفحه عوض می‌شود.
